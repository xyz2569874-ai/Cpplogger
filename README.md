#CppLogger

一个基于C++17实现的轻量级日志系统

##项目介绍

本项目用于学习C++语法和库函数，以及c++项目的设计思想


实现内容：

-策略模式：控制台日志&&文件日志
-日志等级
-线程安全：Mutex锁管理
-日志信息封装
